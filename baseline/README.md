# TerapIA MVP V3 Research-Grade

Abrir `index.html` em navegador moderno.

## O que cresceu
- Jornada integrada check-in → autocuidado → IA → ajuda humana
- Estado local persistente
- Safety Center
- anti-dependency / no diagnosis / no prescription
- Centro de privacidade com export/delete
- agenda local demonstrativa
- admin KB/policies/audit
- research lab separado do cuidado
- dataset sintético longitudinal documentado

## Limites
Não é atendimento psicológico. Não há backend, LLM real ou dados reais nesta baseline.
A versão final deve ser implementada com o Context Pack Codex V3.
