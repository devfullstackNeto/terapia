# Product Spec
Produto: apoio emocional complementar a adolescentes/jovens.

Módulos P0:
- Auth/RBAC
- Onboarding + consent policy
- Mood check-in
- Journal privado
- Self-care library
- Chat RAG grounded
- Safety Center
- Professionals/appointments
- Privacy center
- Aggregated admin dashboard
- KB/policy admin
- Audit
- Research Lab isolado

Jornadas críticas:
1. onboarding -> check-in -> selfcare -> chat -> help/appointment
2. diagnosis/prescription refusal
3. crisis safety flow
4. dependency-safe response
5. privacy export/delete
6. admin publish KB -> chat uses new approved version
